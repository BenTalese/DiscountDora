Likely same information you can see on the dashboard card

E.g.
- Total stock items
- Number of stock items currently selected
- Number of stock items shown (when filter is applied)
- Number of stock items low in stock / out of stock / etc
- Number of stock items in a shopping list
- Number of stock items requiring stock-take

This panel should have a minimal view, and a maximised view
- Minimal view could be just numbers and icons
- Maximised view could be icons, numbers, text, and larger size
- Premium feeling touch would be to automatically transition between mini and maxi look based on size of panel (panel is draggable)
